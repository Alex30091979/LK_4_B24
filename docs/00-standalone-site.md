## Только сайт (без backend) — запуск локально (standalone)

Это режим, когда сайт показывает **demo‑данные** и не требует backend/БД/Bitrix.

Важно: современные браузеры (Chrome/Edge) **блокируют загрузку JS/CSS модулей из `file://`**.
Поэтому нужно запустить маленький локальный сервер (на 1 команду).

### 1) Один раз “собрать” сайт
Откройте PowerShell в корне проекта и выполните:
```bash
npm install
npm run build:standalone -w @lk/web
```

### 2) Открыть в браузере
Запустите локальный сервер:
```bash
npm run preview:standalone -w @lk/web
```

Откройте в браузере:
- `http://127.0.0.1:4173`

Важный момент: в standalone навигация будет через `#` (это нормально), например:
- `http://127.0.0.1:4173/#/login`

### 3) Demo-вход
- client: `client@demo.local` / `Client1234!`
- admin: `admin@demo.local` / `Admin1234!`

### Что в этом режиме НЕ работает
- реальная авторизация/безопасность
- данные из Bitrix24
- база данных

Это только “MVP‑витрина” в браузере. Когда будете готовы подключать данные — включим backend.
