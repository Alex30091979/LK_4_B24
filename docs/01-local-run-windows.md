## Локальный запуск на Windows (очень пошагово)

### Что нужно заранее
- Установлен **Node.js** (у вас уже есть: Node 20+)
- Установлен **Git** (если хотите обновлять проект через `git pull`)

### Шаг 1 — открыть проект
1) Откройте папку проекта:
`...\Google_Scripts\ЛК клиента по рекомендам`
2) Откройте в ней терминал PowerShell.

### Шаг 2 — создать файл настроек API (env.local)
1) Перейдите в `apps/api`
2) Создайте файл **`env.local`** и скопируйте туда содержимое `apps/api/env.local.example`
3) В `env.local` замените эти значения (минимально):
- `JWT_ACCESS_SECRET` — любая длинная строка (20+ символов)
- `JWT_REFRESH_SECRET` — любая длинная строка (20+ символов)
- `DATABASE_URL` — оставьте как есть для MVP

Если Bitrix пока не подключаем — оставьте:
- `BITRIX_MODE=mock`

### Шаг 3 — установить зависимости
В корне проекта выполните:
```bash
npm install
```

### Шаг 4 — создать базу данных и demo-данные
В корне проекта выполните:
```bash
npm run db:migrate -w @lk/api
npm run db:seed -w @lk/api
```

### Шаг 5 — запустить API
В корне проекта:
```bash
npm run dev:api
```
Проверка: откройте в браузере `http://localhost:8080/health` → должно быть `{ "ok": true }`.

### Шаг 6 — запустить Web
Откройте **второй терминал** в корне проекта и выполните:
```bash
npm run dev:web
```
Откройте `http://localhost:5173`.

### Шаг 7 — войти
Demo-логины:
- **client**: `client@demo.local` / `Client1234!`
- **admin**: `admin@demo.local` / `Admin1234!` (попросит 2FA)
