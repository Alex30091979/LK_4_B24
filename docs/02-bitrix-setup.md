## Подключение Bitrix24 (пошагово)

Важно: Bitrix24 у разных компаний устроен по-разному. Поэтому мы подключаемся через **webhook** и задаём имена полей через конфиг.

### Шаг 1 — создать inbound webhook в Bitrix24
1) Откройте Bitrix24 → **Разработчикам** → **Входящий вебхук**
2) Дайте права (минимум):
- CRM: контакты (crm.contact.*)
- CRM: сделки (crm.deal.*)
3) Сохраните:
- `BITRIX_BASE_URL` (пример: `https://company.bitrix24.ru`)
- `BITRIX_WEBHOOK_PATH` (пример: `/rest/1/xxxxx/`)

### Шаг 2 — определить поля (что где хранится)
Нужно понять 2 вещи:
1) **Кто кого рекомендовал**  
В контакте “приведённого клиента” должен быть кастомный field, где хранится ID “рекомендателя”.
Это поле задаётся в:
- `BITRIX_REFERRER_FIELD`

2) **Договор/контракт** (в MVP — “Сделка”)  
Из сделки забираем:
- контакт сделки: `CONTACT_ID` (стандартное)
- дата: по умолчанию `CLOSEDATE` (можно сменить)
- вознаграждение: ваш кастомный field (пример: `UF_CRM_REWARD_AMOUNT`)

Это поля задаются в:
- `BITRIX_DEAL_REWARD_FIELD`
- `BITRIX_DEAL_DATE_FIELD`

### Шаг 3 — включить Bitrix режим в API
Откройте `apps/api/env.local` и выставьте:
- `BITRIX_MODE=real`
- `BITRIX_BASE_URL=...`
- `BITRIX_WEBHOOK_PATH=...`
- `BITRIX_REFERRER_FIELD=...`
- `BITRIX_DEAL_REWARD_FIELD=...`
- `BITRIX_DEAL_DATE_FIELD=...`

Перезапустите API.

### Шаг 4 — выполнить синхронизацию
1) Зайдите в админку (в web) под admin
2) Откройте **Admin → Дерево рекомендаций**
3) Нажмите **Sync Bitrix**

Проверка:
- В **Admin → Аудит** появится запись `admin.bitrix.sync`
